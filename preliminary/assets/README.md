# Fondos v0.9

Assets originales generados con image_gen integrado usando la imagen aportada por el usuario como referencia de estilo. WebP de calidad 95, sin redimensionar. No son mapas extraídos de ROMs.

- camp-gba.webp: prado cenital de 1536 × 1024. Árboles en el perímetro, casa arriba a la izquierda, estanque arriba a la derecha, camino abajo. Centro libre para sprites reales animados.
- routes-gba.webp: atlas de 1536 × 1024, 4 columnas. Límites verticales de las filas: 0, 324, 666, 1024. Pradera, bosque, ribera, cueva; costa, nieve, ruinas, montaña; templo, astral, volcán, pradera.

## Prompt del prado

Original top-down GBA third-generation Pokémon overworld tile aesthetic, discrete square pixels, mint-green grass, rounded layered treetops, 16x16 tile rhythm, dark outlines. Wide 3:2 map, tree border, gray-roof cabin upper left, tiny pond upper right, edge flowers and fences, sand footpath near bottom. Leave center 75% open grass for animated sprites; no characters, Pokémon, text or UI.

## Prompt de rutas

One 4-column × 3-row background atlas in the reference's GBA pixel-art map style. Row-major scenes: meadow, forest, riverbank, cave; coast, snow, ruins, mountain valley; temple, astral crystals, volcanic landscape, meadow. Empty horizontal walkable corridor in each cell's center; scenery along top and bottom. No characters, Pokémon, text or UI.
